## Known porting gotchas (read before Task 1)

These are the Python → Rust translation traps that will bite during execution. Each task below flags the ones relevant to it, but read this list once up front:

1. **Rust's `regex` crate does not support lookbehind.** Python's sentence splitters use `(?<=[.!?])\s+` and `(?<=[.!?])\s+(?=[A-Z])`. Ports must rewrite using `captures_iter` on `([.!?])(\s+)(\p{Upper})` or similar, then compute split offsets manually. This is the trickiest single thing in the port.

2. **`HashMap` iteration order is randomized.** Python's `Counter` and `dict` (3.7+) preserve insertion order. If TF-IDF iteration order differs, floating-point sums drift and byte-identity breaks. Use a paired `Vec<String> + HashMap<String, u32>` structure for anywhere Python iterates a Counter.

3. **`len(s)` vs `s.len()`.** Python `len(str)` counts code points; Rust `str::len()` counts bytes. Fixtures today are ASCII-only, but be precise anyway: use `s.chars().count()` where Python uses `len(s)`, and `char_indices()` for char-index slicing.

4. **`.lower()` vs `to_lowercase()`.** For ASCII fixtures they're identical. For correctness on any future non-ASCII fixture, prefer `to_lowercase()` (matches Python semantics). Do not use `to_ascii_lowercase()` silently — flag if a fixture demands it.

5. **Stable sort.** Python's `sorted()` is stable. Rust's `sort_by` is stable, `sort_unstable_by` is not. Always use the stable variant.

6. **Float comparison for sort.** Use `partial_cmp().unwrap()` only when you've proven no NaN. Prefer `total_cmp` if there's any doubt. Our pipeline's scores are all finite and non-negative, so `partial_cmp().unwrap()` is safe — still flag it.

7. **`math.log` vs `f64::ln`.** Both call into IEEE 754 double-precision natural log. Bit-identical for the same bit-pattern input. Order of operations matters for sums.

8. **String slicing.** Python `text[:n]` slices by character. Rust `&text[..n]` slices by byte. Use `text.char_indices().nth(n).map(|(i, _)| i).unwrap_or(text.len())` to compute the byte offset of the nth character.

9. **Regex flags.** Python's `re.DOTALL` → Rust `(?s)`. `re.IGNORECASE` → `(?i)`. `re.MULTILINE` → `(?m)`. Rust's `regex::Regex::new` compiles once; store in a `static` via `std::sync::LazyLock` (1.80+) or a manual `fn` wrapper around `std::sync::OnceLock` (1.70+). Either works at our MSRV of 1.85.

10. **String returns.** Python functions return `str`. Rust can return `String` or `&str` — return `String` for everything (owned, moves cleanly across the FFI boundary if needed later).

11. **`re.sub(r"\s+$", "", s, flags=re.MULTILINE)`.** Trailing-whitespace per line. Rust regex with `(?m)\s+$` — careful: `$` matches end-of-line in multiline mode, but `\s+` can span newlines by default. Use `[ \t]+$` or `[^\S\n]+$` to scope to horizontal whitespace.

12. **Test case for catching order regressions.** The `tech-spec.txt` benchmark input (and `crm-note-long.txt`) exercise multi-paragraph cases where TF-IDF ordering matters. After any change to tfidf.rs, re-run the fixture walker AND the benchmark to confirm no drift.

```rust
//! Sentence splitter. Mirrors src/skimr/sentences.py byte-for-byte on fixtures.
//!
//! Python's splitter uses lookbehind (`(?<=[.!?])`) and lookahead (`(?=[A-Z])`).
//! Rust's regex crate supports neither. Strategy:
//!   1. Protect abbreviations and decimal numbers with a sentinel char (NUL).
//!   2. Walk match positions of `[.!?]\s+[A-Z]` and `\n\s*\n`, computing split
//!      offsets: split AFTER the punctuation, BEFORE the uppercase letter.
//!   3. Unmask the sentinel.

use regex::Regex;
use std::sync::OnceLock;

const SENTINEL: char = '\u{0000}';

static ABBREVIATIONS: &[&str] = &[
    "mr", "mrs", "ms", "dr", "st", "sr", "jr",
    "inc", "ltd", "co", "corp",
    "vs", "etc", "eg", "ie", "cf",
    "u.s", "u.k", "u.n", "e.u",
    "fig", "no", "vol",
];

fn decimal_re() -> &'static Regex {
    static RE: OnceLock<Regex> = OnceLock::new();
    RE.get_or_init(|| Regex::new(r"(\d)\.(\d)").expect("static regex"))
}

fn abbrev_candidate_re() -> &'static Regex {
    static RE: OnceLock<Regex> = OnceLock::new();
    // Matches a word (allowing internal dots like "U.S") followed by a period.
    // Python: r"\b([A-Za-z]+(?:\.[A-Za-z]+)*)\."
    RE.get_or_init(|| {
        Regex::new(r"\b([A-Za-z]+(?:\.[A-Za-z]+)*)\.").expect("static regex")
    })
}

fn split_point_re() -> &'static Regex {
    static RE: OnceLock<Regex> = OnceLock::new();
    // Paragraph break OR terminal punct + whitespace + uppercase start.
    // Python: r"(?<=[.!?])\s+(?=[A-Z])|\n\s*\n"
    // Rust equivalent via captures: group 1 = punct; group 2 = whitespace (for
    // the punct-start branch); OR group 3 matches `\n\s*\n` entirely.
    RE.get_or_init(|| {
        Regex::new(r"([.!?])(\s+)(?:[A-Z])|(\n\s*\n)").expect("static regex")
    })
}

fn mask(text: &str) -> String {
    if text.contains(SENTINEL) {
        panic!(
            "Input contains reserved sentinel character U+{:04X}",
            SENTINEL as u32
        );
    }

    // Protect decimals: 23.5 -> 23<SENTINEL>5
    let text = decimal_re()
        .replace_all(text, |caps: &regex::Captures| {
            format!("{}{}{}", &caps[1], SENTINEL, &caps[2])
        })
        .into_owned();

    // Protect abbreviations.
    abbrev_candidate_re()
        .replace_all(&text, |caps: &regex::Captures| {
            let word = &caps[1];
            if ABBREVIATIONS.contains(&word.to_lowercase().as_str()) {
                format!("{}{}", word, SENTINEL)
            } else {
                caps[0].to_string()
            }
        })
        .into_owned()
}

fn unmask(text: &str) -> String {
    text.replace(SENTINEL, ".")
}

/// Split text into sentences. Empty input returns an empty Vec.
pub fn split_sentences(text: &str) -> Vec<String> {
    if text.is_empty() {
        return Vec::new();
    }

    let masked = mask(text);

    // Walk split points; build pieces by slicing between split boundaries.
    let re = split_point_re();
    let mut pieces: Vec<&str> = Vec::new();
    let mut cursor = 0usize;

    for caps in re.captures_iter(&masked) {
        let full = caps.get(0).expect("match 0");
        // If the match is the `[.!?]([\s]+)[A-Z]` branch, group 1 + group 2 are present.
        // Split boundary: after the punct char (which is 1 byte; `.!?` are ASCII).
        // If the match is the `\n\s*\n` branch, split at start of the match; drop
        // the newline-run entirely.
        let (split_end, next_start) = if caps.get(1).is_some() {
            let punct = caps.get(1).expect("group 1");
            let ws = caps.get(2).expect("group 2");
            // Uppercase letter follows ws; its byte offset is ws.end().
            (punct.end(), ws.end())
        } else {
            // Paragraph-break branch
            (full.start(), full.end())
        };
        pieces.push(&masked[cursor..split_end]);
        cursor = next_start;
    }
    pieces.push(&masked[cursor..]);

    pieces
        .into_iter()
        .map(str::trim)
        .filter(|p| !p.is_empty())
        .map(unmask)
        .collect()
}
```

```rust
//! TF-IDF + position + length extractive pipeline.
//!
//! Port of src/skimr/tfidf.py. Output is byte-identical to Python for every
//! fixture. Insertion-order iteration of per-sentence token counters is
//! preserved exactly so floating-point sums line up.

use regex::Regex;
use std::collections::HashMap;
use std::sync::OnceLock;

const TFIDF_WEIGHT: f64 = 0.60;
const POSITION_WEIGHT: f64 = 0.25;
const LENGTH_WEIGHT: f64 = 0.15;

/// Stopword list. Must stay byte-identical to Python's `_STOPWORDS` frozenset.
/// See src/skimr/tfidf.py.
static STOPWORDS_LIST: &[&str] = &[
    "the", "and", "that", "this", "with", "for", "are", "was", "were",
    "been", "have", "has", "had", "not", "but", "what", "all", "when",
    "who", "will", "can", "from", "they", "each", "which", "their",
    "there", "about", "would", "make", "more", "some", "into",
    "other", "than", "its", "also", "after", "use", "how", "our",
    "any", "these", "most", "may", "should", "could", "does", "did",
    "just", "because", "over", "such", "through", "very", "your",
    "a", "an", "is", "it", "in", "on", "of", "to", "be", "as", "at", "by",
];

fn stopwords() -> &'static std::collections::HashSet<&'static str> {
    static SW: OnceLock<std::collections::HashSet<&'static str>> = OnceLock::new();
    SW.get_or_init(|| STOPWORDS_LIST.iter().copied().collect())
}

fn token_re() -> &'static Regex {
    static RE: OnceLock<Regex> = OnceLock::new();
    // Python: r"\b[a-z]{3,}\b" — ASCII-only, applied after .lower()
    RE.get_or_init(|| Regex::new(r"(?-u)\b[a-z]{3,}\b").expect("static regex"))
}

/// Insertion-ordered counter. Mirrors Python's Counter(list) insertion order
/// (first occurrence of each key, with running count).
pub(crate) struct OrderedCounter {
    pub keys: Vec<String>,
    pub counts: HashMap<String, u32>,
}

impl OrderedCounter {
    fn new() -> Self {
        Self { keys: Vec::new(), counts: HashMap::new() }
    }

    fn push(&mut self, token: String) {
        if let Some(c) = self.counts.get_mut(&token) {
            *c += 1;
        } else {
            self.keys.push(token.clone());
            self.counts.insert(token, 1);
        }
    }

    fn len_tokens(&self) -> u32 {
        self.counts.values().sum()
    }
}

fn tokenize(sentence: &str) -> OrderedCounter {
    let lowered = sentence.to_lowercase();
    let sw = stopwords();
    let mut counter = OrderedCounter::new();
    for m in token_re().find_iter(&lowered) {
        let tok = m.as_str();
        if !sw.contains(tok) {
            counter.push(tok.to_string());
        }
    }
    counter
}

/// Tokenize + expose just the ordered list (used by some callers).
fn tokenize_list(sentence: &str) -> Vec<String> {
    let lowered = sentence.to_lowercase();
    let sw = stopwords();
    let mut out = Vec::new();
    for m in token_re().find_iter(&lowered) {
        let tok = m.as_str();
        if !sw.contains(tok) {
            out.push(tok.to_string());
        }
    }
    out
}

fn normalize(scores: &[f64]) -> Vec<f64> {
    let hi = scores.iter().cloned().fold(f64::NEG_INFINITY, f64::max);
    if !hi.is_finite() || hi <= 0.0 {
        return vec![0.0; scores.len()];
    }
    scores.iter().map(|s| s / hi).collect()
}

/// TF-IDF score per sentence, normalized to [0, 1].
#[must_use]
pub fn tfidf_score(sentences: &[String]) -> Vec<f64> {
    let tokenized: Vec<OrderedCounter> = sentences.iter().map(|s| tokenize(s)).collect();
    let n = sentences.len();

    // Document frequency. Only values matter, not iteration order.
    let mut df: HashMap<String, u32> = HashMap::new();
    for tc in &tokenized {
        // set(tokens) in Python → dedupe before incrementing df
        for key in &tc.keys {
            *df.entry(key.clone()).or_insert(0) += 1;
        }
    }

    // IDF: log((n+1)/(freq+1)) + 1
    let n_f = n as f64;
    let idf: HashMap<String, f64> = df
        .into_iter()
        .map(|(term, freq)| (term, ((n_f + 1.0) / (freq as f64 + 1.0)).ln() + 1.0))
        .collect();

    let raw: Vec<f64> = tokenized
        .iter()
        .map(|tc| {
            if tc.keys.is_empty() {
                return 0.0;
            }
            // Iterate keys in insertion order — mirrors Python's `for term in tf`.
            let sum: f64 = tc
                .keys
                .iter()
                .map(|k| {
                    let count = f64::from(*tc.counts.get(k).expect("key must exist"));
                    let idf_val = *idf.get(k).unwrap_or(&0.0);
                    count * idf_val
                })
                .sum();
            let total_tokens = f64::from(tc.len_tokens());
            sum / total_tokens
        })
        .collect();

    normalize(&raw)
}

/// Position score: endpoints score 1.0, middle scores lowest. U-shaped.
#[must_use]
pub fn position_score(n: usize) -> Vec<f64> {
    if n == 0 {
        return Vec::new();
    }
    if n == 1 {
        return vec![1.0];
    }
    let denom = (n - 1).max(1) as f64;
    let raw: Vec<f64> = (0..n)
        .map(|i| {
            let d = i.min(n - 1 - i) as f64 / denom;
            (1.0 - 2.0 * d).max(0.0)
        })
        .collect();
    normalize(&raw)
}

/// Length score. Peaks in 10-30 word range.
#[must_use]
pub fn length_score(sentences: &[String]) -> Vec<f64> {
    let raw: Vec<f64> = sentences
        .iter()
        .map(|s| {
            let words = s.split_whitespace().count();
            if words == 0 {
                0.0
            } else if (10..=30).contains(&words) {
                1.0
            } else if words < 10 {
                words as f64 / 10.0
            } else {
                // words > 30
                (1.0 - (words as f64 - 30.0) / 50.0).max(0.0)
            }
        })
        .collect();
    normalize(&raw)
}

/// Composite: 0.60 * tfidf + 0.25 * position + 0.15 * length.
#[must_use]
pub fn composite_score(sentences: &[String]) -> Vec<f64> {
    if sentences.is_empty() {
        return Vec::new();
    }
    let t = tfidf_score(sentences);
    let p = position_score(sentences.len());
    let l = length_score(sentences);
    (0..sentences.len())
        .map(|i| TFIDF_WEIGHT * t[i] + POSITION_WEIGHT * p[i] + LENGTH_WEIGHT * l[i])
        .collect()
}
```

```rust
// --- summarize pipeline (port of the 7-step flow from src/skimr/tfidf.py) ---

const MIN_SENTENCES: usize = 3;
const MIN_BUDGET_FOR_SENTENCES: usize = 50;

/// Truncate to `max_length` CHARACTERS (not bytes), appending `"..."` if the
/// text didn't already fit. Matches Python's len(str)-as-chars semantics.
fn truncate(text: &str, max_length: usize) -> String {
    let char_count = text.chars().count();
    if char_count <= max_length {
        return text.to_string();
    }
    let body_budget = max_length.saturating_sub(3);
    let byte_end = text
        .char_indices()
        .nth(body_budget)
        .map_or(text.len(), |(i, _)| i);
    let mut out = text[..byte_end].to_string();
    out.push_str("...");
    out
}

/// Extractive summary of `text` capped at `max_length` characters.
#[must_use]
pub fn summarize(text: &str, max_length: usize) -> String {
    if text.is_empty() {
        return String::new();
    }
    if text.chars().count() <= max_length {
        return text.to_string();
    }
    if max_length < MIN_BUDGET_FOR_SENTENCES {
        return truncate(text, max_length);
    }

    let sentences = crate::sentences::split_sentences(text);
    if sentences.len() < MIN_SENTENCES {
        return truncate(text, max_length);
    }

    let scores = composite_score(&sentences);

    // Sort indices by (-score, index). Stable sort preserves original index on ties.
    let mut indices: Vec<usize> = (0..sentences.len()).collect();
    indices.sort_by(|&a, &b| {
        let sa = -scores[a];
        let sb = -scores[b];
        sa.partial_cmp(&sb)
            .expect("no NaN in pipeline scores")
            .then(a.cmp(&b))
    });

    let mut selected: Vec<usize> = Vec::new();
    let mut used = 0usize;
    let separator_chars = 1usize;
    for idx in indices {
        let sentence = &sentences[idx];
        let sent_chars = sentence.chars().count();
        let needed = sent_chars + if selected.is_empty() { 0 } else { separator_chars };
        if used + needed <= max_length {
            selected.push(idx);
            used += needed;
        }
    }

    if selected.is_empty() {
        return truncate(text, max_length);
    }

    selected.sort_unstable();
    selected
        .into_iter()
        .map(|i| sentences[i].clone())
        .collect::<Vec<_>>()
        .join(" ")
}
```

```rust
/// SQL-style splitter: replace `\n+` with `". "`, split after terminal punct
/// when followed by whitespace. Keep only segments > 20 chars (trimmed).
/// Mirrors Python's `_split_sql_style`.
fn split_sql_style(text: &str) -> Vec<String> {
    // Python: re.sub(r"\n+", ". ", text)
    static NL_RE: OnceLock<Regex> = OnceLock::new();
    let nl = NL_RE.get_or_init(|| Regex::new(r"\n+").expect("static regex"));
    let normalized = nl.replace_all(text, ". ");

    // Python: r"(?<=[.!?])\s+"  — split AFTER terminal punct.
    // Lookbehind unavailable; walk matches of `[.!?](\s+)` and split after the punct.
    static SPLIT_RE: OnceLock<Regex> = OnceLock::new();
    let split = SPLIT_RE.get_or_init(|| Regex::new(r"[.!?]\s+").expect("static regex"));

    let mut parts: Vec<&str> = Vec::new();
    let mut cursor = 0usize;
    for m in split.find_iter(&normalized) {
        // Split right AFTER the punct char (1 byte; `.!?` are ASCII).
        // m.start() is at the punct; the punct byte is m.start()..m.start()+1.
        let after_punct = m.start() + 1;
        parts.push(&normalized[cursor..after_punct]);
        cursor = m.end();
    }
    parts.push(&normalized[cursor..]);

    parts
        .into_iter()
        .map(str::trim)
        .filter(|p| p.chars().count() > 20)
        .map(str::to_string)
        .collect()
}

/// Port of `extract_sentences(input_text, keywords, num_sentences)` from
/// extractive_functions.sql.
#[must_use]
pub fn extract_keyword(text: &str, keywords: &str, num_sentences: usize) -> String {
    if text.is_empty() {
        return String::new();
    }

    // Parse keywords: lowercase, split on whitespace, drop tokens <= 2 chars,
    // dedupe, sort (Python: sorted({...})).
    let kw_set: BTreeSet<String> = keywords
        .split_whitespace()
        .map(str::to_lowercase)
        .map(|s| s.trim().to_string())
        .filter(|s| s.chars().count() > 2)
        .collect();
    if kw_set.is_empty() {
        // SQL: LEFT(input_text, 2000) — char-based per Python semantics.
        let end = text
            .char_indices()
            .nth(2000)
            .map_or(text.len(), |(i, _)| i);
        return text[..end].to_string();
    }
    let keyword_list: Vec<String> = kw_set.into_iter().collect();

    let sentences = split_sql_style(text);
    if sentences.is_empty() {
        return text.to_string();
    }

    let mut scored: Vec<(f64, usize, String)> = sentences
        .iter()
        .enumerate()
        .map(|(i, s)| {
            let lower = s.to_lowercase();
            let mut score = keyword_list.iter().filter(|kw| lower.contains(kw.as_str())).count() as f64;
            if s.chars().count() > 200 {
                score += 0.5;
            }
            if digit_re().is_match(s) {
                score += 0.3;
            }
            if causal_re().is_match(&lower) {
                score += 1.0;
            }
            (score, i, s.clone())
        })
        .collect();

    // Stable sort by (-score, index)
    scored.sort_by(|a, b| {
        let sa = -a.0;
        let sb = -b.0;
        sa.partial_cmp(&sb)
            .expect("no NaN")
            .then(a.1.cmp(&b.1))
    });

    scored.into_iter()
        .take(num_sentences)
        .map(|(_, _, s)| s)
        .collect::<Vec<_>>()
        .join("\n")
}
```

```rust
fn json_str(cfg: &str, key: &str) -> Option<String> {
    let needle = format!("\"{key}\":");
    let start = cfg.find(&needle)? + needle.len();
    let after = cfg[start..].trim_start();
    if !after.starts_with('"') {
        return None;
    }

    let close = after.find('"')?;
    Some(after[..close].to_string())

    let after = cfg[start..].trim_start();

        "strip_think" => Some(skimr::strip_think(input)),
```

```rust
//! skimr CLI. Hand-rolled arg parser — no external deps.
//!
//! Usage:
//!   skimr [FILE] --mode {tfidf,keyword,clean_text,strip_think} [OPTIONS]

use std::io::{Read, Write};
use std::process::ExitCode;

#[derive(Debug)]
struct Args {
    path: Option<String>,
    mode: String,
    max_chars: usize,
    keywords: String,
    top: usize,
}

impl Default for Args {
    fn default() -> Self {
        Self {
            path: None,
            mode: "tfidf".to_string(),
            max_chars: 500,
            keywords: String::new(),
            top: 10,
        }
    }
}

fn print_help(to: &mut impl Write) {
    let _ = writeln!(
        to,
        "Usage: skimr [FILE] --mode {{tfidf,keyword,clean_text,strip_think}} [OPTIONS]\n\
         Reads FILE or stdin, writes summary to stdout.\n\
         \n\
         Options:\n\
         \x20\x20--mode MODE         Summarization mode (default: tfidf)\n\
         \x20\x20--max-chars N       Char budget for tfidf (default: 500)\n\
         \x20\x20--keywords STR      Space-separated keywords for keyword mode\n\
         \x20\x20--top N             Sentences to return in keyword mode (default: 10)\n\
         \x20\x20-h, --help          Show this help"
    );
}

fn parse_args(argv: impl Iterator<Item = String>) -> Result<Args, String> {
    let mut args = Args::default();
    let mut iter = argv.peekable();
    while let Some(arg) = iter.next() {
        match arg.as_str() {
            "-h" | "--help" => {
                print_help(&mut std::io::stdout());
                std::process::exit(0);
            }
            "--mode" => {
                let v = iter.next().ok_or_else(|| "--mode requires an argument".to_string())?;
                if !["tfidf", "keyword", "clean_text", "strip_think"].contains(&v.as_str()) {
                    return Err(format!("invalid --mode value: {v}"));
                }
                args.mode = v;
            }
            "--max-chars" => {
                let v = iter.next().ok_or_else(|| "--max-chars requires an argument".to_string())?;
                args.max_chars = v.parse().map_err(|_| format!("--max-chars not numeric: {v}"))?;
            }
            "--keywords" => {
                args.keywords = iter.next().ok_or_else(|| "--keywords requires an argument".to_string())?;
            }
            "--top" => {
                let v = iter.next().ok_or_else(|| "--top requires an argument".to_string())?;
                args.top = v.parse().map_err(|_| format!("--top not numeric: {v}"))?;
            }
            _ if arg.starts_with("--") => return Err(format!("unknown flag: {arg}")),
            _ => {
                if args.path.is_some() {
                    return Err(format!("unexpected positional argument: {arg}"));
                }
                args.path = Some(arg);
            }
        }
    }
    Ok(args)
}

fn read_input(path: &Option<String>) -> std::io::Result<String> {
    match path.as_deref() {
        Some(p) if p != "-" => std::fs::read_to_string(p),
        _ => {
            let mut s = String::new();
            std::io::stdin().read_to_string(&mut s)?;
            Ok(s)
        }
    }
}

fn main() -> ExitCode {
    let argv: Vec<String> = std::env::args().skip(1).collect();
    let args = match parse_args(argv.into_iter()) {
        Ok(a) => a,
        Err(msg) => {
            let _ = writeln!(std::io::stderr(), "error: {msg}");
            return ExitCode::from(2);
        }
    };

    let text = match read_input(&args.path) {
        Ok(t) => t,
        Err(e) => {
            let _ = writeln!(std::io::stderr(), "error reading input: {e}");
            return ExitCode::from(1);
        }
    };

    let output = match args.mode.as_str() {
        "tfidf" => skimr::summarize(&text, args.max_chars),
        "keyword" => {
            if args.keywords.is_empty() {
                let _ = writeln!(std::io::stderr(), "error: --mode keyword requires --keywords");
                return ExitCode::from(2);
            }
            skimr::extract_keyword(&text, &args.keywords, args.top)
        }
        "clean_text" => skimr::clean_text(&text),
        "strip_think" => skimr::strip_think(&text),
        _ => unreachable!("parse_args validates mode"),
    };

    let mut out = std::io::stdout().lock();
    let _ = out.write_all(output.as_bytes());
    if !output.ends_with('\n') {
        let _ = out.write_all(b"\n");
    }
    ExitCode::SUCCESS
}
```

- [ ] **Step 1: Extend harness with a Rust subprocess measurement**

Adding a subprocess-per-call measurement in Python pays a process-spawn tax that dominates the microbench. A better approach: add a small helper binary in the Rust crate that times itself and emits JSON.

Create `rust/src/bin/bench_tfidf.rs`:

```rust
//! Micro-benchmark for skimr tfidf. Reads stdin, times N iterations, prints
//! {"p50_ms": X, "p95_ms": Y, "out_chars": Z}.

use std::io::Read;
use std::time::Instant;

fn main() {
    let mut text = String::new();
    std::io::stdin().read_to_string(&mut text).unwrap();

    let iterations: usize = std::env::args()
        .nth(1)
        .and_then(|s| s.parse().ok())
        .unwrap_or(100);

    // Warmup
    let _ = skimr::summarize(&text, 500);

    let mut samples: Vec<f64> = Vec::with_capacity(iterations);
    for _ in 0..iterations {
        let t0 = Instant::now();
        skimr::summarize(&text, 500);
        samples.push(t0.elapsed().as_nanos() as f64 / 1e6);
    }
    samples.sort_by(|a, b| a.partial_cmp(b).unwrap());
    let p50 = samples[samples.len() / 2];
    let p95 = samples[(0.95 * samples.len() as f64) as usize];
    let out = skimr::summarize(&text, 500);
    println!(
        r#"{{"p50_ms":{p50:.6},"p95_ms":{p95:.6},"out_chars":{oc}}}"#,
        oc = out.chars().count()
    );
}
```

Add the target to `rust/Cargo.toml`:

```toml
[[bin]]
name = "bench_tfidf"
path = "src/bin/bench_tfidf.rs"
```

Modify `benchmarks/harness.py` to call this helper in a release build:

```python
# near the top, after existing imports
import json as _json
import subprocess as _sp

RUST_BENCH_BIN = BENCH_ROOT.parent / "rust" / "target" / "release" / "bench_tfidf"


def _rust_tfidf_measure(text: str, iterations: int) -> tuple[float, float, int]:
    """Run the Rust bench_tfidf helper. Returns (p50_ms, p95_ms, out_chars)."""
    if not RUST_BENCH_BIN.exists():
        raise SystemExit(
            f"Rust bench binary not found at {RUST_BENCH_BIN}.\n"
            "Build with: cd rust && cargo build --release"
        )
    proc = _sp.run(
        [str(RUST_BENCH_BIN), str(iterations)],
        input=text,
        capture_output=True,
        text=True,
        check=True,
    )
    data = _json.loads(proc.stdout.strip())
    return data["p50_ms"], data["p95_ms"], data["out_chars"]
```

Then update the `RUST_PLACEHOLDERS` list and the rendering loop: now compute a real cell for `rust-skimr/tfidf`, keep `rust-skimr/textrank` as `—`.

The simplest refactor: add a separate `RUST_MEASURERS` dict with functions that return `(p50, p95, out_chars)` directly, and loop over it alongside `SUMMARIZERS`. Keep the render unchanged otherwise.
